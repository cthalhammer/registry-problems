# RegistryProblems

The canonical Lean statements of the open problems on
[clopen.solutions](https://clopen.solutions), one module per problem. Each
problem's page on the site, such as https://clopen.solutions/OP-00001/, shows
its statement and a starter for submitting against it.

A submission imports the statement it targets and proves it, or its negation:

```lean
import RegistryProblems.OP_00001

theorem resolution : RegistryProblems.Problem_OP_00001 := ...
```

Generated by the site from the statements marked canonical there; do not edit
by hand. Statements formalised elsewhere credit their source and licence in
their module's header, with the licence texts under `LICENSES/`.
